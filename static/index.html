Cloud setup checklist

  1. Create a private bucket in your chosen cloud provider.
  2. Use a dedicated least-privilege service identity.
  3. Store credentials in environment variables, never in Git/source code.
  4. Enable encryption, access logging, retention and backups.
  5. Upload only approved data and test restore before relying on it.
